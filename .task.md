# Watch Collector Logbook PWA

## Goal
A React PWA for watch collectors — offline, no cloud, no account. Sell for $19 one-time on Gumroad.

## Market Context
- r/Watches 1.8M members, collectors with $1K-$100K+ in watches
- Existing apps require cloud/subscriptions — collectors want privacy
- Current go-to: Google Sheets. Clear gap for a polished offline alternative.

## Core Features (MVP — 1 night)
1. **Add watch** — detailed form:
   - Brand, Model, Reference, Serial number
   - Movement (Auto/Manual/Quartz), Case material, Case size (mm)
   - Purchase price, Purchase date, Seller
   - Current estimated value
   - Condition (Mint/Excellent/Good/Fair)
   - Service history (multiple entries per watch with date + notes)
   - Box & papers (yes/no), Notes
   - Photos (base64 in IndexedDB, up to 5 per watch)
2. **Collection grid** — card view with photo, brand/model, P&L %
3. **Portfolio dashboard**:
   - Total cost vs estimated value
   - Overall P&L
   - Breakdown by brand
4. **Service reminders** — list watches overdue for service (>5 years)
5. **Export** — PDF report via jsPDF (for insurance) + CSV
6. **PWA** — installable, offline

## Tech Stack
- React 18 + TypeScript + Vite + TailwindCSS
- Dexie.js (IndexedDB)
- jsPDF + html2canvas (PDF export)
- vite-plugin-pwa
- Premium design: dark (#0a0a0a) + gold accents (#d4af37)
